# 开放式画册 / Open Prospectus

保存自选定的第二套视觉方向。只保留该方案的页面系统，不包含另外两套方向、轮播选择器或 Codex 专属接口。

## 视觉规范

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#f7f9fc` |
| 正文与标题 | `#122d53` |
| 辅助文字 | `#52647b` |
| 强调色、主按钮 | `#164ab4` |
| 分隔线 | `#d1dbe7` |
| 白色 Logo 底板 | `#112b51` |
| 页脚背景 | `#edf2f8` |

字体采用系统无衬线字体和 PingFang SC / Microsoft YaHei 中文回退，不请求远程字体。正文 14px，辅助文字 11-13px，桌面标题随容器宽度缩放。内容最大宽度 1280px，桌面两侧留白 36px，手机 22px。

## 页面构图

- 主页：品牌导航、支持单位、标题与介绍分栏、横幅主视觉、时间地点、赛道、奖项、页脚。
- 赛制页：大标题、页内目录、赛道切换、规则摘要、FAQ、往届资料。
- 介绍页：活动定位、发展历程与按职责分组的团队。
- 600px 以下采用手机布局，导航折叠，保留语言及报名入口。
- 中英文共用组件但独立呈现；标题和按钮按实际长度自然适配。

## 品牌素材

主视觉沿用原海报，通过 CSS `object-fit` 和 `object-position` 实现横幅裁切，保留原文件。UESTC、ST 和 Glasgow 的白字版本置于深蓝底板上。Glasgow 原文件透明边距较大，CSS 只隐藏其画布空白，保持有效标识的原色及比例。蓝字版本也存档备用。

## 动画与交互

- 首页首次进入：标题、说明、操作和海报依次轻微上移淡入，每项 360ms，间隔 45ms。
- 页面切换：180ms 上移和透明度过渡。
- 按钮悬停上移 2px，赛道入口轻微水平反馈。
- 无循环背景、强制滚动、视差或阻塞阅读的遮罩。
- `prefers-reduced-motion` 关闭非必要动画和过渡。
- FAQ 使用原生 `details/summary`，弹窗使用原生 `dialog`，支持 Escape 和焦点返回。
- 切换语言不重建 FAQ 容器，保留展开状态。URL 支持语言、赛道及区块定位。

## 内容状态

海报和 Logo 是提供的真实素材；日期、场地、赛道规则、奖项、历程、成员和外部链接待确认。标题和介绍属于当前样板展示文案。
