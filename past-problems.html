Welcome to the Kelvin Programming Competition 2025

The IP Track - Official Rules and Guidelines

Please read the following rules carefully before you begin. Your participation implies acceptance of these terms. Good luck!

  • Eligibility: You are participating in The IP Track, which is exclusively for students enrolled in the UESTC1005_UESTCHN1005: Introductory Programming (2025-26) course.
  • Competition Time: The competition will be held from 10:30 to 13:30 on December 7, 2025. Submissions made outside this official time frame will not be graded, unless an official extension is announced by the organizers based on site conditions.
  • Submission and Grading: Your sole method of submission is the CodeGrade platform. Your score will be determined automatically by the CodeGrade AutoTest system. No other forms of assessment will be accepted.
  • Authorized Equipment: You may only use the provided laboratory computers. The only authorized software is Dev C++ and the CodeGrade online editor. The use of any other electronic devices and software (e.g., VS Code) is strictly prohibited.
  • Language Limitation: Only C programming language is allowed.
  • Academic Integrity: You are strictly forbidden from using any AI tools to assist in writing code or understanding the problems. You are also prohibited from asking any person for help regarding the problem content. Any violation of these rules will result in immediate disqualification - you’ll not be eligible for the cash awards anymore.
  • Problems and Ranking: This competition consists of 3 problems.
    • Final ranking is determined first by the total score (the sum of all three problems).
    • In case of a tie in score, the participant with the earlier submission time will be ranked higher.

The Trials of the Sunstone Citadel

You are the Code Knight, a seeker of lost lore and forgotten magic. After a perilous journey, you stand before the legendary Sunstone Citadel, a fortress of ancient wisdom locked away by three great trials. You are not the only seeker today; other brave adventurers are also attempting to prove their merit. A glowing runic inscription on the main archway dictates the terms of the challenge for all aspirants:

The Citadel’s magic will observe your progress. Your ultimate rank among seekers is determined first by your Total Score. Should two seekers achieve equal success, the one who demonstrated greater Swiftness (submit earlier) shall be deemed superior.

The gateway hums, awaiting your first answer. To prove your worth and gain entry, you must solve the riddles left by the Citadel’s architects. Your quest begins now.

Level 1: The Gate of Prime Sigils

The first trial is the gateway itself. It is sealed by a complex magical lock that responds only to special numbers known as ”Prime Sigils.” An inscription carved into the archway reveals the secret: a Prime Sigil is a number that is both a prime and a palindrome.

To deactivate the barrier, you must identify all Prime Sigils operating within the range [a, b]. Write a program to find all palindromic primes in the range [a, b].

Definition 1: Prime Number

A prime number (or a prime) is a natural number greater than 1 that has no positive divisors other than 1 and itself, such as 2, 3, 5, 7 and so on.

Definition 2: Palindrome

A palindrome is a natural number that reads the same forwards and backwards, like 151, 12321, 4334 and so on.

1.1 Input Format

The first line contains two positive integers a and b.

1.2 Output Format

Output a list of palindromic primes, one per line.

For this problem, [a, b] denotes the set of natural numbers ≥a and ≤b, where 5 ≤a < b ≤ 100, 000, 000.

Level 2: The Scroll of Unveiling

The text on the scroll is a powerful incantation, but it’s written in an ancient, compressed runic language used by the Citadel’s builders to save space on their enchanted artifacts. Only by deciphering the full, decompressed chant can you command the Inner Sanctum doors to open.

The builders’ compression rule is as follows: several consecutive identical substrings X are compressed into the form [DX] (D is an integer and 1 ≤D ≤99). For example, the string CBCBCBCB is compressed to [4CB] or [2[2CB]].

The builders call a compressed string like [2[2CB]] a double compression since it involves the compression of an already compressed string. As a further example, the builders would refer to [2[2[2CB]]] as a triple compression.

Now we give you the compressed incantation from the scroll. You must decompress it to reveal the true words of power.

Notes

It is guaranteed to contain only digits, uppercase letters, [ and ].

2.1 Input Format

Input one line, a string, representing the compressed incantation.

2.2 Output Format

Output one line, a string, representing the decompressed result.

2.3 Sample IO

Input

AC[3FUN]

Output

ACFUNFUNFUN

Hints

You must pay attention to the following inputs and corresponding outputs. They will occur rarely, but you must account for them if you want full marks. CD[1HN] <=> CDHN CD8HN <=> CD8HN HN3[2CD] <=> HN3CDCD [13IP] <=> IPIPIPIPIPIPIPIPIPIPIPIPIP [2[2IP]]HN[2CD]6 <=> IPIPIPIPHNCDCD6

2.4 Data Range

For at least 50% of the data: The length of the decompressed string is no more than 100 characters, with at most triple compression. For 100% of the data: The length of the decompressed string is no more than 5000 characters, with at most ten levels of compression.

Level 3: The Guardian’s Tribute

You speak the final, decompressed word of the incantation. With a deep grinding of stone, the massive doors to the Inner Sanctum rumble open. The final chamber is lit by a single, massive crystal. Seated on a throne before it is the Citadel’s Guardian, an ancient elemental being.

The Guardian demands some crystals from you to exchange the Citadel’s secrets. It wants to know that you are prepared for any eventuality.

You have access to N types of ”Essence Crystals”, each representing a specific numerical value (positive integer), and you can take an unlimited quantity of each from the magical field around you.

To prove your efficiency, you must carry as few crystals as possible, while still being able to form any value from 1 to X. The Guardian will test you by asking for a random value in this range (1 ≤value ≤X). You must ensure that the subset of crystals you carry can sum up to any requested value.

What is the minimum number of Essence Crystals you must carry to pass this final trial?

3.1 Input Format

The first line contains two integers X, N. The next N integers denote the denomination of each type of Essence Crystal.

3.2 Output Format

Output the minimum number of crystals you need to carry. If there is no solution, the program should output -1.

3.3 Sample I/O

Input

20 4
1 2 5 10

Output

5

Explanation

The output is 5 because you need to carry a minimum of 5 ”Essence Crystals” to be able to form any value from 1 to 20. A valid combination that achieves this minimum is: • One crystal with value 1 • Two crystals with value 2 • One crystal with value 5 • One crystal with value 10 Total crystals carried: 1 + 2 + 1 + 1 = 5. With this set of crystals {1, 2, 2, 5, 10}, you can create every value from 1 (using just the 1) all the way up to 20 (using all of them: 1 + 2 + 2 + 5 + 10 = 20). (e.g., 1 + 2 + 10 = 13)

Hints

• If crystals with value 1 are not provided, is it possible to form any value? • If crystals with value 1 are the only one provided, how many crystals you would like to bring? • Please don’t worry about the test data. We design multiple cases for different algorithms to make sure you can get the score you deserve. Just try your best to optimize your code.

3.4 Data Range

For at least 30% of the data, N ≤5, X ≤100. For at least 70% of the data, N ≤10, X ≤1000. For some data, there are some special cases to test the robustness of your algorithm.

HypnosTech — The Sleep Architect

Objective

Your objective is to write a program that generates an audio playback sequence with a duration of T minutes, maximizing the total sleep integral produced by this sequence in terms of mathematical expectation. The program needs to automatically calculate the optimal action path based on the input state transition matrix and reward function. You may choose to use C, C++ or Python to complete the challenge.

3.2 States

The brain has N discrete states. Example with N = 5: • S0: Awake • S1: Light Sleep • S2: Deep Sleep • S3: REM • S4: Waked Up

3.3 Actions

The system supports M types of soundscapes (sound effects), e.g., A0 (silence), A1 (white noise), A2 (thunderstorm sound).

3.4 Dynamics

3.4.1 Transition Matrix

For each action a ∈[a0, . . . , aM−1], there is an N×N matrix P (a). P (a)

i,j represents the probability of transitioning to state j in the next minute when the current state is i and sound effect a is playing.

3.4.2 Generalized Cognitive Switching Penalty

To model the biological cost of changing neural states, the switching penalty is defined by a Cost Matrix CN×N. Let Ci,j be the cost of switching soundscapes (at̸ = at−1) when the brain transitions from State i to State j.

The penalty at time t is calculated as:

Penaltyt=I(at≠at−1)CSt−1,St(3.1)Penalty_t=\mathbb I(a_t\ne a_{t-1})C_{S_{t-1},S_t}\tag{3.1}Penaltyt​=I(at​=at−1​)CSt−1​,St​​(3.1)

For t = 1, assume at−1 = a0 = 0. Noted that in basic cases, this matrix simplifies to a uniform structure where all off-diagonal costs equal a constant 0. For example, Ci,j = 0 for all i̸ = j.

3.4.3 Time-Variant Reward System (Value Wandering)

Rewards follow a Mean-Reverting Process. They follow a Mean-Reverting Process with an invariant centroid, preventing the brain from ”locking” into a single state. As time progresses, high-value states naturally drift towards the system average, while low-value states recover, periodically inverting their relative advantages. The reward for state s at time t is calculated as:

Where:

• μ: The system’s average reward centroid

• L: The wandering cycle period. If L = 0, rewards remain static: R(s, t) = Rinitial(s).

• Rinitial(s): The base reward input for state s.

Noted that if L = 0 in the input, the rewards remain static (R(s, t) = Rinitial(s)).

3.4.4 Initial Condition

The system is in State 0 (S0) at time t = 0 with a probability of 1.0.

• P(S0 = 0) = 1.0

• P(S0 = k) = 0 for all k̸ = 0

3.5 Optimization Objective

Objective Function:

Let A = [a1, a2, . . . , aT ] be the sequence of actions chosen for each minute t.

The total expected score J(A) is defined as:

Where :

• St is the random variable representing the sleep state at time t.

• I(·) is the indicator function (1 if switching occurs, 0 otherwise).

• E[·] is the expectation taken over the stochastic transitions defined by matrices P(at).

Input & Output

All data is read through standard input (stdin).

4.1 Input Format

The input consists of the following structure:

T N M L Type
R0 R1 ... RN-1
[Switching Penalty Matrix]
[Matrix block Action 0]
[Matrix block Action 1]
...
[Matrix block Action M-1]

Line 1: Four integers

• T: Total duration (minutes).

• N: Number of states.

• M: Number of sound effects.

• L: Cycle period for reward wandering. If L = 0, R(s, t) = Rinitial(s).

• Type: Constraint mode identifier.

Line 2: Base Rewards

• N integers representing the initial base rewards Rinitial(s).

Switching Penalty Matrix

An N × N integer matrix block always follows, regardless of the Type value.

• If Type = 1 (Generalized Matrix Penalty Mode): The value at row i, column j represents the specific switching penalty Ci,j.

• If Type = 0 (Uniform Penalty Mode): The matrix block is still provided to maintain input format consistency, but all values in this matrix will be 0. Your program should ignore the values in this matrix and assume the penalty is 0 (Static K = 0).

Matrix Blocks

The following M blocks each represent a transition matrix for a sound effect. Each block contains N rows, with N floating-point numbers (0.0 to 1.0) per row. The number in the i-th row and j-th column represents P(Statei →Statej). The sum of each row is guaranteed to be 1.0.

4.2 Output Format

Output a single line containing the sequence of sound effect IDs formatted as a JSON-style list:

[a1, a2, . . . , aT ]

Each integer represents the sound effect ID selected for this minute (from 0 to M −1). Separators must strictly be a comma followed by a space.
